# UP - The Yogi Years
An independent, source-linked research publication about Uttar Pradesh under Chief Minister Yogi Adityanath, from 19 March 2017 to the present research cutoff of 18 October 2026.

## Read the publication
https://ashish-bhatia.github.io/UP_The_Yogi_Years/

## Research scope
- 19 research dossiers covering economy, fiscal policy, livelihoods, poverty, welfare, nutrition, healthcare, education, crime, justice, rights, roads, environment, elections and district inequality.
- 31 clickable primary, audited, independent or government-attributed source records.
- Interactive before/after comparisons with explicit years, denominators and caveats.
- Chronological event ledger, 18 divisions / 75 districts and a prioritized evidence backlog.
- Independent editorial methodology. Findings are not partisan endorsements or accusations.

## Deploy with GitHub Pages (main branch; no Actions workflow required)
1. Open repository **Settings → Pages**.
2. Choose **Build and deployment → Source → Deploy from a branch**.
3. Choose **Branch: main**, **Folder: / (root)**, then **Save**.
4. The site is at https://ashish-bhatia.github.io/UP_The_Yogi_Years/ after GitHub publishes it. If GitHub Pages is already enabled, this commit publishes automatically.

This repository contains static HTML/CSS/JavaScript and does not require npm, a framework or GitHub Actions.

## Editorial safeguards
- Official claims are attributed. Budget estimates, revised estimates, actuals, signed MoUs and operating projects are separate concepts.
- Compare the same indicator and geographical scope where possible; explain exceptions.
- NFHS 2015-16 predates the current government. NFHS-5 covers 2020-21 in UP and does not alone prove causal attribution.
- The UP district SDG score of 68.72 is **not** the same series as the NITI national state SDG score of 67.
- Recorded offences do not equal all crimes committed.
- The district directory contains **names**, not made-up district scores.
- Correct erroneous information with source links and exact dates via GitHub Issues.
