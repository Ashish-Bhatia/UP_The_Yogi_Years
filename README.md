# UP - The Yogi Years

An independent online editorial examination of outcomes in Uttar Pradesh from March 2017 onward.

**Public site:** https://ashish-bhatia.github.io/UP_The_Yogi_Years/

## Sections
- **The verdict**: outcome-led editorial ratings, including an explicit **Not rated** designation where the available data are insufficient.
- **Investigations**: policy stories addressing the outcome, comparative evidence, qualifications and final assessment.
- **The numbers**: interactive comparisons with dates and definitions, chart/table views and downloadable CSV.
- **Timeline**: major developments in chronological order.
- **75 districts**: directory organised by administrative division.
- **Source library**: linked public records, surveys, budget analyses, reports and court documents.
- **Editorial method**: transparent criteria governing grades and attribution.

Ratings are editorial interpretations of cited data, **not** mathematically validated government-performance scores. No overall government grade is implied. The publication distinguishes surveys from government announcements, budget estimates from actual expenditure, and reporting from adjudication.

## Static site
The website is served from the root of `main` through GitHub Pages. It uses HTML, CSS and plain JavaScript. No build step, packages, CMS or Actions workflows are required.

Enable GitHub Pages at **Settings → Pages → Deploy from a branch → main / (root)**.
